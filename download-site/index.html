G:

Hermes Agent для Windows

Полный исходник Nous Research Hermes Agent, собранный в один установщик. Распаковка идёт на диск G.

Скачать Hermes-Agent-Setup.exe

Hermes-Agent-Setup.exe · около 99 МБ · Windows 10 или новее

  • Что внутри. Весь исходный код Hermes Agent, не урезанная сборка.
  • Куда ставится. Если диск G готов и свободно хотя бы 4 ГБ, файлы распаковываются в G:\hermes. Диск C не заполняется.
  • Если диска G нет. Установщик кладёт файлы в %LOCALAPPDATA%\hermes.
  • Первый запуск. Исходники уже в файле. Git и Python докачиваются в ту же папку. Потом в новом окне PowerShell выполните hermes.
